## Decisions / findings (worth remembering)

1. **1M context + harness memory don't obsolete Pipekit's discipline** — the risk is *contaminated judgment, not lost memory*, so a bigger window doesn't relax stage isolation. The persistence layer those capabilities would gut was already pruned in the 4.7 cycle. Enforcement is the durable value.
2. **`/pr-fix`'s old "only ≥80 survive, silence > noise" suppressed real findings at the find stage** — exactly the failure Anthropic's refreshed 4.8 "Code review harnesses" guidance warns about. Fixed coverage-first, then rebuilt as two-axis: severity (impact) and confidence (likelihood) kept independent, with an **INVESTIGATE** quadrant for high-severity/low-confidence.
3. **`pr-review-toolkit` (properly configured) ≥ `/pr-fix` on review depth.** `/pr-fix`'s durable edge is intent + cross-spec-scan + dedup + interactive fix + Linear integration — not the review engine. So Phase 3 is now engine-pluggable (native `pr-review-toolkit` default, **fail-loud**, `--engine=builtin` fallback), mirroring `/work`'s backend model.
4. **Single-pass LLM review is high-variance** — same toolkit, same PR (#408): 0 Critical (run 1, opus-4-7) vs ~4 Critical (run 2, opus-4-8 + test agent + priming). Run 2× on high-stakes (`--runs=N`).
5. **`pr-review-toolkit` is Anthropic first-party** (`claude-plugins-official`, Apache-2.0, actively maintained). NOT carried by `sync-method.sh` → native engine is a plugin dependency; `builtin` is the portable path.
6. **`/strategy-sync` fresh-chat is correct for 4.8** — it's deliberate anti-contamination isolation, not a window workaround. Polished the wording to say so (PR #94).
7. **Commit-format hook bug:** false-positives on multi-`-m` commits (validates the `Co-Authored-By` trailer, not the subject).
